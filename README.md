# Accurate-Cyber-Star-v0.0.2
Accurate-Cyber-Star v0.0.2 is a lightweight cybersecurity research and learning tool designed to support ethical hacking, network analysis, and security awareness.
It provides structured workflows, clear insights, and modular components for cyber drills, testing simulations, and skill development, helping students and professionals strengthen defensive and offensive cybersecurity capabilities responsibly.

## How to clone the repo
```bash
git clone https://github.com/Iankulani/Accurate-Cyber-Star-v0.0.2
cd Accurate-Cyber-Star-v0.0.2
```
## How to run
```bash
python3 Accurate-Cyber-Star-v0.0.2.py
```
